# 18. 홈 화면 메인 제목 및 안내 문구 수정 계획서

## 1. 개요 및 사용자 요구사항
1. **홈 화면 메인 제목 수정**:
   - 기존: `제니트리 e-Label 쇼룸`
   - 수정: `제니트리 쇼룸` (" e-Label" 문구 삭제)
2. **홈 화면 서브 안내 문구 수정**:
   - 기존: `제품을 선택하시면 상세 전자라벨 정보 및 전성분을 확인하실 수 있습니다.`
   - 수정: `제품을 선택하시면 제품 정보 및 견적을 의뢰하실 수 있습니다.`

---

## 2. 세부 구현 계획
- `index.html` 내의 메인 타이틀 엘리먼트(`#maker-title`) 및 안내 문구(`#maker-desc`):
  - HTML 마크업 기본 텍스트 수정
  - 자바스크립트 다국어 라벨 객체(`uiLabels.makerTitle`, `uiLabels.makerDesc`) 업데이트

---

## 3. 검증 계획
1. Puppeteer를 통해 홈 화면 스크린샷 캡처
2. 타이틀이 "제니트리 쇼룸"으로 변경되었는지 확인
3. 안내 문구가 "제품을 선택하시면 제품 정보 및 견적을 의뢰하실 수 있습니다."로 변경되었는지 확인
