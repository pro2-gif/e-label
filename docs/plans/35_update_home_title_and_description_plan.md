# 계획서 35: 홈 화면 메인 제목 및 안내 문구(부제목) 변경

## 1. 개요 및 목적
- **요청 사항**:
  - 홈 화면 메인 제목을 기존 `"제품 라인업"`에서 `"제니트리 제품 정보 안내"`로 변경.
  - 부제목을 기존 `"제품을 선택하시면 제품 정보 확인 및 견적을 의뢰하실 수 있습니다."`에서 `"제품을 선택하시면 제품 상세 설명, 카탈로그를 확인하실 수 있습니다."`로 변경.
- **배경**:
  - 제품 구매하기 및 견적 의뢰 버튼이 삭제됨에 따라, 공식 제품 정보와 카탈로그를 제공하는 플랫폼의 본질에 맞추어 카피라이트를 명확하고 정돈되게 개편.

---

## 2. 변경 계획

### `index.html`
1. 초기 HTML 요소 수정:
   - `<h1 id="maker-title">`: `"제니트리 제품 정보 안내"`
   - `<p id="maker-desc">`: `"제품을 선택하시면 제품 상세 설명, 카탈로그를 확인하실 수 있습니다."`
2. 다국어 `uiLabels` 업데이트:
   - `makerTitle`:
     - `ko`: `"제니트리 제품 정보 안내"`
     - `en`: `"Janytree Product Information"`
     - `jp`: `"ジェニツリー製品情報のご案内"`
     - `ch`: `"Janytree产品信息指南"`
     - `tw`: `"Janytree產品資訊指南"`
   - `makerDesc`:
     - `ko`: `"제품을 선택하시면 제품 상세 설명, 카탈로그를 확인하실 수 있습니다."`
     - `en`: `"Select a product to view detailed descriptions and catalogs."`
     - `jp`: `"製品を選択すると、製品の詳細説明とカタログをご確認いただけます。"`
     - `ch`: `"选择产品即可查看产品详细说明及目录。"`
     - `tw`: `"選擇產品即可查看產品詳細說明及目錄。"`

## 3. 검증 계획
1. `npm.cmd run build` 번들 정상 빌드.
2. Puppeteer 화면 캡쳐로 홈 화면(PC/모바일) 상단에 지정된 문구가 정확하고 미려하게 출력되는지 확인.
