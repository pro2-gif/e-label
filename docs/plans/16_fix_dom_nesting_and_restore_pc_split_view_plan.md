# 16. DOM 조기 닫힘 버그 해결, 상단 좌/우 2단 배치 복원 및 하단 2열 영상/채널 정돈 계획서

## 1. 개요 및 사용자 피드백 정밀 분석
1. **홈 화면 하단 뷰어 노출 버그 해결**:
   - 현상: 홈 화면 제품 카드 아래에 뷰어의 테이블과 소개영상이 노출됨.
   - 원인: 이전 편집 중 `</div>` 태그가 2개 초과로 닫히면서 `#viewer-container`와 `#main-content`가 상단에서 조기 종료되어, 하단 테이블 및 비디오가 컨테이너 바깥(body)으로 탈출함.
   - 조치: DOM 태그 계층 구조를 완벽하게 정상화하여, 홈 화면에서는 하단 뷰어 내용이 100% 완벽히 격리되도록 수정.
2. **상단 히어로 좌우 2단 배치 복원**:
   - 사용자 요청: "바로 전 화면처럼 제품 이미지는 좌측, 제품명, 카달로그보기, 견적 문의는 우측에 표기되게"
   - 구성:
     - **좌측**: 제품 이미지 (360px 사각 래퍼)
     - **우측**:
       1. 제품명
       2. 서브탭 (라뉴필의 경우 [필링 워시], [앰플 부스터] 단락 없이 나열)
       3. [제품 카탈로그 보기 (PDF)]
       4. [제품 견적 의뢰 ➔]
3. **정보 테이블 좌우 폭 최적화 (780px)**:
   - DOM이 정상화되면 테이블이 780px 폭 안으로 쏙 들어가며, 모니터 전체로 퍼지는 현상이 완벽하게 해결됨.
4. **하단 소개영상 및 공식 채널 복원 (2열 나란히 배치)**:
   - 사용자 요청: "소개 영상에서 유튜브 동영상 사이즈를 줄이니까 작아지는데 바로 전 화면 처럼 해줘"
   - 조치: 비디오를 혼자 덩그러니 작게 두지 않고, 바로 전 화면처럼 좌측(소개영상)과 우측(공식 채널 링크)이 2열 그리드로 조화롭게 배치되도록 복원.

## 2. 세부 구현 내용
- `index.html` DOM 구조 정밀 교정 (div 짝맞춤 100% 일치)
- CSS `@media (min-width: 860px)`:
  - `.main-content`: `max-width: 780px !important;`
  - `.product-hero-layout`: `grid-template-columns: 360px 1fr; gap: 36px;`
  - `.video-and-links-grid`: `grid-template-columns: 1fr 1fr; gap: 24px;`
- 서브탭: [필링 워시] [앰플 부스터] 단락 없이 한 줄 나열 유지
- 카탈로그 보기 버튼을 견적의뢰 버튼 바로 위(우측 열)에 배치

## 3. 검증 계획
1. 홈 화면(`index.html`) 접속 시 하단에 테이블이나 영상이 일절 노출되지 않는지 확인 (DOM 높이 및 스크린샷 검증).
2. 제품 상세 화면(`?c=CLX-LAP`) 접속 시:
   - 좌측에 이미지, 우측에 제품명 + [필링 워시] [앰플 부스터] + 카탈로그 + 견적의뢰가 깔끔하게 2단 배치되는지 확인.
   - 테이블이 780px 폭으로 단정하게 제한되는지 확인.
   - 하단 소개영상과 채널 목록이 2열로 나란히 배치되는지 확인.
