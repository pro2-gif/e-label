# Plan 27: 라뉴필 세트 수정 이미지(lanupeel_set.jpg) 적용 및 캐시 갱신 계획서

## 1. 개요 및 원인 분석
- **사용자 요청 사항**:
  - "라뉴필 제품 이미지의 경우 수정해서 바탕화면 폴더에 넣었는데 이미지 수정이 되지 않아"
- **원인 분석**:
  1. **파일 형식 차이**: 사용자가 수정한 새 이미지는 `lanupeel_set.jpg` (JPEG, 59KB) 파일로 프로젝트 루트(`C:\Users\user\Desktop\e-label\lanupeel_set.jpg`)에 저장되었으나, 기존 소스코드는 `lanupeel_set.png` (PNG, 3MB)로 고정되어 있었습니다.
  2. **Vite 정적 자산 경로**: 웹 프로젝트에서 이미지가 실서비스에 정상 노출되려면 `public/` 디렉토리에 위치해야 하며, `vite build` 시 `dist/`로 배포 복사되어야 합니다.
  3. **브라우저 캐시**: 이전에 로드된 구버전 이미지가 사용자 브라우저에 캐시되어 있을 수 있으므로 캐시 버스팅 파라미터가 필요합니다.

---

## 2. 작업 계획
1. **이미지 동기화**:
   - `lanupeel_set.jpg`를 `public/lanupeel_set.jpg`로 복사.
   - `public/lanupeel_set.png`에도 동일 이미지 기반으로 복사/동기화하여 어떤 경로로 요청되어도 최신 이미지가 로드되도록 보장.
2. **코드 수정 (`index.html`)**:
   - 홈 화면 라뉴필 대표 이미지 경로를 `lanupeel_set.jpg?v=20261102` 로 업데이트.
   - `.jpg`와 `.png` 모두 안정적으로 지원.
3. **빌드 및 검증**:
   - `npm.cmd run build`로 `dist/`에 배포 자산 동기화.
   - Puppeteer로 홈 화면의 라뉴필 카드가 새 수정 이미지(상자+2종 바이알 병)로 완벽히 표시되는지 확인 및 스크린샷 캡처.
4. **Git 개별 파일 스테이징 및 커밋 & 푸시**:
   - 변경 파일만 안전하게 커밋하고 실서버에 즉시 푸시하여 배포 완료.
