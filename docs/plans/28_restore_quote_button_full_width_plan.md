# Plan 28: 제품 견적 의뢰 버튼 전체 너비(풀 와이드) 복원 계획서

## 1. 개요 및 목적
- **사용자 요청 사항**:
  - "제품 견적 의뢰 PC 화면이 너무 좁아서 이상해보여. 기존처럼 그냥 길게 할게"
- **현상 분석**:
  - PC 화면에서 제품 상세 표 너비(1240px) 대비 버튼이 440px로 좁게 들어가면서, 표와의 가로 비율상 다소 좁고 이질감이 발생함.
  - 사용자의 요청에 따라 가로 너비를 표 전체 너비에 맞추어 `width: 100%`로 길게 복원.
  - 앞서 적용한 세련된 화이트 문서 아이콘(`description`)은 유지하여 완성도를 보존.

---

## 2. 작업 상세 내용
### CSS 수정 (`index.html`)
- `.standalone-quote-card`에서 `max-width: 440px !important;` 및 `margin: 0 auto !important;`를 제거.
- `width: 100%;` 및 기존 패딩(`padding: 18px 26px;`)으로 복원하여 표의 양 끝과 완벽하게 정렬되는 풀 와이드 카드로 복원.

---

## 3. 검증 계획
- Puppeteer 브라우저 테스트:
  - PC 1440px에서 `.standalone-quote-card`의 너비가 표와 동일하게 컨테이너(1240px) 전체 너비로 렌더링되는지 확인.
  - 스크린샷 캡처 및 시각적 검증.
- 개별 파일 스테이징, 커밋 후 수인의 푸시 요청 처리.
