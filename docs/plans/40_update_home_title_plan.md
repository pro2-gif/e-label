# 40_update_home_title_plan.md

## 작업 개요
- **목적**: 홈 화면 메인 제목 문구 변경 ("제니트리 제품 정보 안내" -> "제니트리 제품 정보")
- **배경**: 사용자의 요청에 따라 불필요한 '안내' 수식어를 제외하고 보다 명확하고 직관적인 '제니트리 제품 정보'로 문구 정돈

## 대상 파일 및 수정 위치
- `index.html`:
  1. 1078행: 정적 HTML `<h1 id="maker-title">제니트리 제품 정보</h1>`
  2. 1703행: 다국어 객체 `uiLabels.makerTitle.ko = "제니트리 제품 정보"`

## 검증 계획
- `npm.cmd run build` 실행하여 빌드 검증
- Puppeteer 스크립트로 홈 화면 메인 제목이 "제니트리 제품 정보"로 정상 노출되는지 스크린샷 캡처 확인
