# 병합 셀 구조 기반 세트 상품 서브탭 자동 생성 구현 계획

구글 시트의 병합 셀 구조(세트 상품)를 인식하여, 하나의 제품 안에서 구성품별로 탭을 이동하며 정보를 확인할 수 있도록 구현하는 계획입니다.

## User Review Required

> [!IMPORTANT]  
> **UI 디자인 확인**
> 서브탭 버튼은 가로 스크롤이 가능한 버튼 그룹 형태로 대표 이미지 하단에 추가될 예정입니다. JT 디자인 시스템의 가이드라인(여백, 모서리 둥글기 등)을 참고하여 구현하지만, 별도의 앱 고유 색상(브랜드 컬러)을 우선적으로 상속받아 자연스럽게 매칭되도록 합니다. 
> 
> **다국어 번역 안내**
> '구성품명' 탭 버튼 역시 다국어 모드(영문, 일본어, 중국어)로 전환 시 구글 번역기를 통해 실시간 번역됩니다.

## Proposed Changes

### `index.html` (메인 애플리케이션 파일)

#### 1. 컬럼 매핑 업데이트 (`initColumns` 함수)
- 시트에서 '구성품명' 또는 '구성품명_국문'을 찾아 인덱스를 저장할 수 있도록 `COL.componentName` 변수를 추가합니다.

#### 2. 셀 병합 보정 및 데이터 그룹화 (`loadSheetData` 함수)
- 구글 시트 데이터를 2차원 배열로 읽어올 때, **Forward-Fill (상속) 로직**을 적용합니다.
  - 현재 행의 `제품코드`, `제품명`, `이미지`, `구매링크`가 비어있다면, 바로 이전 행의 데이터를 자동으로 채웁니다.
- 동일한 `제품코드`를 가진 행들을 묶어서 **세트 상품(Set Product)** 객체로 그룹화합니다.
  - 기존의 로직(단일 상품)과 완벽하게 호환되도록, 첫 번째 행 데이터를 대표 배열로 유지하되, 내부 속성으로 `components` 배열을 추가하여 모든 구성품 행을 저장합니다.

#### 3. 서브탭 UI 구조 추가 (HTML)
- `<main class="main-content">` 안의 대표 이미지(`product-image-wrapper`) 바로 아래에, 서브탭 버튼들이 들어갈 컨테이너 `<div id="sub-tabs-container">`를 새로 추가합니다.
- 기본적으로 단일 상품일 때는 숨김 처리(`display: none`) 됩니다.

#### 4. 동적 렌더링 로직 개편 (`renderLabel` 함수)
- **공통 정보 렌더링**: 제품명, 대표 이미지, 제조업자, 구매하기 링크 등 세트 전체에 공통으로 적용되는 정보는 한 번만 그립니다.
- **서브탭 생성**: 
  - `item.components`의 길이가 2 이상일 경우 세트 상품으로 판별하여, 각 구성품 이름으로 탭 버튼을 생성합니다.
  - 다국어 모드 시 구성품명도 번역하여 버튼에 표시합니다.
- **개별 구성품 렌더링 함수 분리 (`updateComponentData`)**:
  - 기존 `renderLabel` 내에 있던 용량, 기능성, 전성분, 핵심 성분, 사용방법 등의 테이블 업데이트 로직을 떼어내어 `updateComponentData(comp, lang)` 함수로 만듭니다.
  - 탭을 클릭할 때마다 이 함수를 호출하여 하단의 정보 테이블 내용만 즉시 교체합니다.

## Verification Plan

### Manual Verification
- **구글 시트 갱신 테스트**: 시트에 세트 상품(제품코드가 같고 구성품이 여러 행인 제품)과 단일 상품이 섞여 있을 때, 모두 정상적으로 파싱되는지 확인합니다.
- **뷰어 화면 확인**: 
  - 세트 상품 QR로 접속 시 제품 이미지 아래에 구성품 서브탭이 나타나는지 확인합니다.
  - 단일 상품 접속 시 서브탭 없이 기존처럼 렌더링되는지 확인합니다.
- **탭 클릭 상호작용**: 탭을 클릭했을 때 하단의 용량, 전성분, 사용방법 등의 데이터가 선택한 구성품의 데이터로 올바르게 바뀌는지 확인합니다.
- **다국어 테스트**: 언어를 변경했을 때 서브탭의 이름과 내부 상세 정보들이 올바르게 번역되는지 확인합니다.
- **TTS 테스트**: 탭 전환 후 TTS 재생 버튼을 눌렀을 때, 현재 화면에 보이는 구성품의 정보를 정상적으로 읽어주는지 확인합니다.
