# 계획서 21: 버튼 흰색 배경 통일, 서브탭 라뉴필 전용 한정, 홈 화면 제품 코드 삭제

## 1. 개요 및 목적
- **목적**:
  1. [제품 견적의뢰], [제품 구매하기] 버튼 배경을 [제품 카탈로그 보기]와 동일한 **화이트 카드형 버튼**으로 완벽 통일.
  2. [필링 워시], [앰플 부스터] 서브탭을 **오직 '인투메디 클리닉스 라뉴필'(CLX-LAP)** 전용으로 엄격 제한 (그 외 전 제품에서 서브탭 완전 숨김).
  3. 홈 화면(쇼룸 그리드) 제품 카드에서 제품 코드(예: CLX-RJ, CLX-WH 등)를 일괄 삭제하여 제품명만 정갈하게 노출.

---

## 2. 세부 변경 사항

### A. 버튼 스타일 및 구조 화이트 카드형 통일
- 대상 버튼: `.hero-quote-btn`, `.hero-buy-btn`, `.catalog-link-card`
- 스타일 규칙:
  - 배경: `background-color: var(--color-on-primary, #ffffff);`
  - 테두리: `border: 1px solid var(--color-border);`
  - 글자색: `color: var(--color-text, #1F2328);`
  - 폰트 크기: `14px`, 굵기 `600`
  - 패딩: `13px 18px`
  - 모서리 둥글기: `12px`
  - 그림자: `0 1px 3px rgba(0, 0, 0, 0.04)`
  - 구조: 좌측 [아이콘 + 텍스트], 우측 [바로가기 아이콘 `open_in_new`] 양끝 정렬 (`justify-content: space-between`)
  - 호버 효과: 은은한 배경 변화 (`var(--color-bg-layout)`), 그림자 및 살짝 띄우기

### B. 서브탭 라뉴필(`CLX-LAP`) 전용 엄격 제한
- `renderLabel` 함수 내에서 해당 제품이 라뉴필(`CLX-LAP` 또는 '라뉴필')인지 검사:
  - **라뉴필인 경우**: `sub-tabs-container`를 `display: flex`로 표시하고 [필링 워시], [앰플 부스터] 탭 렌더링.
  - **라뉴필이 아닌 모든 제품**: `sub-tabs-container`의 `display: none` 적용 및 `innerHTML = ''` 비움 처리.
  - 이를 통해 '클리닉스 화이트' 등 다른 모든 제품에서 서브탭이 노출되지 않도록 완벽 차단.

### C. 홈 화면 제품 코드 삭제
- `renderProductGrid` 함수에서 카드 바디 내 `${codeDisplay ? `<div class="product-card-code">${codeDisplay}</div>` : ''}` 코드 완전 제거.
- 홈 화면 카드에 제품명과 하단 액션 버튼만 깔끔하게 노출.

---

## 3. 검증 계획
1. **화이트(`CLX-WH`) 상세 페이지**: 서브탭([필링 워시], [앰플 부스터])이 노출되지 않고 바로 제품 정보 테이블이 표시되는지 확인.
2. **라뉴필(`CLX-LAP`) 상세 페이지**: 정상적으로 [필링 워시], [앰플 부스터] 2개 서브탭이 노출되는지 확인.
3. **버튼 3종 통일 확인**: 카탈로그 보기, 견적 의뢰, 구매하기 3개 버튼이 모두 동일한 흰색 배경과 스타일로 일치하는지 확인.
4. **홈 화면 쇼룸 확인**: 제품 카드에서 제품 코드가 삭제되고 깔끔하게 표시되는지 확인.
