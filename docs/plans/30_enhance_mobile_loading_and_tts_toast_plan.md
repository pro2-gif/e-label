# Plan 30: 모바일 홈 화면 로딩 스피너 및 TTS 음성 안내 안내 토스트 강화 계획서

## 1. 개요 및 원인 분석
- **사용자 피드백**:
  1. "음성이 나오지 않는데?"
  2. "그리고 모바일에서 홈화면이 나오지 않아" (캡처본 첨부)
- **현상 및 원인 분석**:
  1. **홈 화면 로딩 상태 부재**:
     - 실서버 배포 직후 접속 시 또는 모바일 무선 네트워크 환경에서 Supabase 데이터 로딩(1~2초) 동안 홈 화면의 카드 영역이 완전히 비어 있어, 사용자가 화면이 나오지 않는 것으로 오인함.
     - 배포 전파 타이밍 또는 브라우저 캐시로 인해 최초 데이터 호출 지연 발생.
  2. **모바일 iOS 사파리 음성(TTS) 무음 특성**:
     - 아이폰(iOS Safari)은 기기 측면의 **무음(진동) 스위치**가 켜져 있으면 브라우저 음성합성(TTS) 소리가 시스템 차원에서 무음 처리됨.
     - 또한 모바일 브라우저 오디오 큐 락으로 인해 첫 터치 시 볼륨이나 오디오 컨텍스트 활성화 피드백이 필요함.

---

## 2. 작업 상세 내용
### 1) 홈 화면 초기 로딩 스피너(Loading Indicator) 추가
- `#product-card-grid` 기본 HTML에 세련된 애니메이션 로딩 스피너와 `"제품 목록을 불러오는 중입니다..."` 안내 문구를 기본 배치.
- 데이터 로드 완료 즉시 제품 카드로 부드럽게 교체하여, 네트워크 지연 중에도 빈 화면이 아닌 로딩 중임을 직관적으로 인지할 수 있도록 개선.

### 2) TTS 음성 재생 시 모바일 친화적 안내 토스트(Toast) 팝업 추가
- 스피커 버튼(헤더 전체 스피커 또는 표 안의 항목 스피커) 클릭 시:
  - 화면 하단에 세련된 다크 글래스모피즘 스타일의 토스트 메시지 노출:
    `"🔊 음성 안내를 시작합니다. (소리가 안 들리실 경우 기기의 무음 모드를 해제하고 미디어 음량을 확인해 주세요)"`
  - 3.5초 후 부드럽게 페이드아웃.
  - 사용자가 스마트폰의 진동 스위치나 볼륨을 즉각 확인할 수 있도록 극초보자 맞춤 안내 제공.

### 3) 오디오 언락 강화
- 스피커 버튼 터치 시 `window.speechSynthesis.resume()` 및 무음 오디오 컨텍스트 활성화 로직 보강.
