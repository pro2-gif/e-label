# 뷰티 전자라벨(e-label) 핵심 컨셉 성분 팝업 기능 구현 계획

본 계획서는 구글 시트의 전성분을 분석하여 핵심 컨셉 성분을 추출하고, 이를 뱃지 형태의 UI로 표시한 뒤 터치 시 상세 설명 팝업을 띄워주는 기능에 대한 설계 문서입니다.

## User Review Required

> [!IMPORTANT]
> **구글 시트 확장 관련**
> 추가적인 성분 설명 데이터를 구글 시트에서 관리하실 경우, 시트의 **13번째 열(M열)**에 `컨셉성분설명` 항목을 만들어두시면 해당 데이터를 최우선으로 읽어오도록 설계할 예정입니다.
> 
> *데이터 입력 방식 예시:*
> `히알루론산:#수분공급 - 수분 꽉!, 병풀추출물:#진정 - 피부 편안!` (이러한 형태로 입력)

## Open Questions

> [!WARNING]
> 현재 `index.html` 내부에 `<script>` 형태로 로직이 모두 들어있고, 별도의 `script.js` 파일도 존재하여 코드가 양분되어 있습니다. 
> 이전 작업처럼 두 파일(index.html, script.js) 모두에 코드를 동일하게 업데이트하는 방식으로 진행해도 괜찮을지 확인 부탁드립니다.

## Proposed Changes

---

### [Component 1] UI 및 스타일 업데이트 (index.html, style.css)

#### [MODIFY] index.html
- **[핵심 컨셉 성분 섹션]**: 전성분 표시 구역(`<tr>`) 바로 위에 새로운 `<tr>`을 추가하여 핵심 컨셉 성분을 보여주는 구역을 만듭니다.
- **[모달 팝업 구조]**: 화면 최하단 쪽에 화면 중앙에 나타날 모달 팝업과 어두운 배경(Overlay), 닫기(X) 버튼을 구성하는 HTML 뼈대를 추가합니다.
- **[CSS 스타일]**: 
  - 클릭 가능한 예쁜 배지(Badge) 형태의 성분 태그 스타일 추가
  - 모달 오버레이(배경 블러 처리 등) 및 팝업 창 애니메이션, 둥근 디자인(Border-radius) 적용

---

### [Component 2] JavaScript 로직 업데이트 (index.html, script.js)

#### [MODIFY] index.html
#### [MODIFY] script.js
- **[예비 데이터(Fallback) 추가]**: 
  - 나이아신아마이드, 아데노신, 히알루론산, 병풀추출물 등 주요 화장품 성분들의 기본 효능/설명 데이터 딕셔너리(`conceptFallbackDesc`)를 상단에 하드코딩으로 세팅합니다.
- **[데이터 확장 및 로딩 로직 수정]**: 
  - `loadSheetData` 함수에서 읽어오는 열 갯수를 12개에서 13개로 확장하여, 13번째 열(인덱스 12)의 컨셉성분설명 데이터를 읽어올 수 있도록 수정합니다. (`COL.conceptDesc = 12` 추가)
- **[핵심 성분 추출 로직]**: 
  - 구글 시트에서 가져온 '국문 전성분' 텍스트를 읽어, `conceptFallbackDesc`(또는 시트에서 읽어온 추가 데이터)의 키(Key)값들과 비교(includes 매칭)합니다.
  - 매칭된 주요 성분들을 3~5개 추출하여 HTML 태그(배지)로 렌더링합니다.
- **[클릭/터치 모달 이벤트]**:
  - 생성된 뱃지를 누르면 모달창에 해당 성분명과 설명을 세팅하고 화면에 표시하는 로직(`openIngredientModal`, `closeIngredientModal`)을 추가합니다.
  - 팝업 바깥쪽 어두운 배경을 터치해도 창이 닫히도록 이벤트를 추가합니다.

## Verification Plan

### Manual Verification
1. 브라우저에서 `index.html`을 로컬로 열고 새로고침(F5)합니다.
2. 성분 사전에 등록된 성분(예: 나이아신아마이드 등)이 포함된 제품을 선택합니다.
3. 전성분 윗줄에 "✨ 핵심 컨셉 성분" 태그 뱃지가 예쁘게 나타나는지 확인합니다.
4. 해당 뱃지를 터치(클릭)했을 때 중앙에 팝업창(모달)이 뜨고 설명이 잘 나타나는지 확인합니다.
5. X 버튼이나 화면 바깥쪽을 클릭했을 때 모달창이 정상적으로 닫히는지 확인합니다.
