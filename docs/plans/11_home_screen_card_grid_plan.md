# 홈화면 쇼룸형 카드 그리드(옵션 1) 개편 구현 계획서

## 1. 개요
* **목적**: 기존의 드롭다운 하나만 덩그러니 있던 첫 화면(`https://e-label.janytree.app/`)을, 전체 12개 제품의 실물 사진과 제품명이 시원하게 펼쳐지는 **쇼룸형 카드 그리드(쇼핑몰/갤러리 스타일)**로 전면 개편.
* **사용자 선택**: 옵션 1 (제품 카드 갤러리 ➔ 카드 클릭 시 해당 제품의 전자라벨 상세 정보로 즉시 이동).

---

## 2. 세부 구현 내용

### 1) 홈화면 UI 레이아웃 개편 (`index.html`)
* **헤더 섹션**:
  * 제니트리 공식 로고 (상단 중앙 정렬)
  * 다국어 지원 헤드라인 타이틀: `e-Label 제품 라인업` (KO, EN, JP, ZH-CN, ZH-TW)
  * 설명 문구: `확인하고자 하는 제품을 선택하시면 상세 전자라벨 정보 및 전성분을 확인하실 수 있습니다.`
* **반응형 제품 카드 그리드 (`#product-card-grid`)**:
  * PC/대화면: 3~4열 그리드 (`max-width: 1040px; margin: 0 auto;`)
  * 태블릿: 2~3열 그리드
  * 모바일: 1~2열 그리드
* **제품 카드 디자인 (JT 디자인 시스템 준수)**:
  * 카드 프레임: 화이트 배경, 16px 라운드, 은은한 테두리 및 그림자, 호버 시 위로 4px 부드럽게 부상(`translateY(-4px)`).
  * 대표 이미지: 정사각형 1:1 비율, 여백 포함 깔끔한 `object-fit: contain`.
  * 메타 정보: 제품 식별 코드 뱃지 + 다국어 제품명 (2줄 말줄임 안전 처리).
  * 카드 전체 클릭 시 ➔ 해당 제품의 전자라벨 정보 페이지로 즉시 전환.
  * 카드 내 [QR] 전용 버튼 ➔ 클릭 시 QR 코드 다운로드 팝업 모달 호출.

### 2) QR 코드 다운로드 전용 팝업 모달 (`#qr-modal`)
* 기존 홈화면에 있던 필수 관리자 기능(PNG / SVG 고해상도 QR 다운로드)을 100% 보존.
* 제품 카드에서 QR 버튼을 누르면 내부 모달로 고해상도 QR 이미지와 함께 [PNG 다운로드], [SVG 다운로드], [라벨 정보 바로보기 ↗] 버튼 제공.

### 3) 실시간 다국어 동기화 (`currentLang`)
* 상단 언어 선택 버튼(`KO`, `EN`, `JP`, `ZH-CN`, `ZH-TW`)을 클릭하면,
  홈화면의 헤드라인뿐만 아니라 **그리드 안의 모든 제품명이 선택한 언어로 실시간 자동 변환**.
* 기기 언어 자동 감지(`getDevicePreferredLanguage`)와도 완벽 연동되어 해외 바이어가 홈화면으로 직접 들어와도 자기 나라 언어로 제품 카드들이 정렬됨.

### 4) 상세 화면에서 홈으로 복귀 흐름
* 상세 라벨 화면 하단의 [돌아가기] 버튼 클릭 시 ➔ 매끄럽게 홈화면 카드 그리드로 복귀.

---

## 3. 검증 및 배포 절차
1. 로컬 환경에서 12개 제품 카드가 누락 없이 이미지와 함께 완벽히 렌더링되는지 확인.
2. PC, 태블릿, 모바일 해상도별 반응형 그리드 동작 검증.
3. 카드 클릭 시 상세 라벨 화면 전환 및 상세에서 [돌아가기] 시 카드 목록 복귀 동작 확인.
4. 상단 언어 변경 시 카드 텍스트 실시간 전환 확인.
5. 수인에게 완료 보고 후 클라우드 배포(Push).
