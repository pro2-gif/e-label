# 12. "홈으로" 버튼 문구 변경 및 제품 카드 이미지 규격 통일 계획서

## 1. 개요
- **요청 1**: 라벨 상세 페이지 하단의 [돌아가기] 버튼 문구를 [홈으로]로 변경
- **요청 2**: 홈 화면 제품 쇼룸 카드의 이미지가 세로형/정사각형 등에 따라 제각각으로 늘어나 카드의 높낮이가 불규칙해지는 현상을 해결하여, 모든 카드와 이미지를 단정하고 일관된 1:1 규격으로 통일

---

## 2. 세부 작업 내용

### 1) "돌아가기" -> "홈으로" 문구 변경
- **대상 파일**: `index.html`
- **수정 위치**:
  1. 하단 푸터 버튼 기본 텍스트: `돌아가기` -> `홈으로`
  2. 다국어 라벨 매핑(`uiLabels.homeBtn`):
     - `ko`: "돌아가기" -> "홈으로"
     - `en`: "Go Back" -> "Home"
     - `jp`: "戻る" -> "ホームへ"
     - `ch`: "返回" -> "首页"
     - `tw`: "返回" -> "首頁"

### 2) 제품 카드 이미지 규격 및 카드 높이 완전 통일
- **문제 원인**:
  - Flexbox/Grid 내부에서 자식 이미지의 세로 해상도가 큰 경우(`버블폼`, `크림` 등), 부모인 `.product-card-img-wrap`의 `min-height: auto` 기본 특성 때문에 `aspect-ratio: 1/1`이 무시되고 세로로 팽창함.
  - 결과적으로 특정 카드만 세로로 길쭉해져 전체 그리드의 행 높이가 불규칙해짐.
- **해결 방안**:
  1. `.product-card-img-wrap` 스타일 보강:
     - `aspect-ratio: 1 / 1;` 유지
     - `min-height: 0; min-width: 0;` 명시 (CSS Flexbox/Grid 팽창 버그 차단)
     - `overflow: hidden;` 적용
     - `padding: 14px;` (적절한 내부 여백으로 제품 이미지가 답답하지 않게 여유 확보)
  2. `.product-card-img` 스타일 보강:
     - `width: 100%; height: 100%;` 강제
     - `object-fit: contain;` (가로세로 왜곡 없이 사각형 영역 안에 온전히 수납)
     - `object-position: center;`
  3. `.product-card` 스타일 보강:
     - `height: 100%;` 적용으로 동일 행의 모든 카드 높이를 100% 동일하게 일치

## 3. 검증 계획
1. Puppeteer 자동화 테스트로 각 카드의 높이(`getBoundingClientRect().height`)와 이미지 래퍼의 높이가 완벽히 균일한지 측정.
2. 스크린샷을 촬영하여 11개 제품 카드의 정렬 상태와 하단 "홈으로" 버튼 문구 확인.
3. 사용자에게 결과 보고 후 클라우드 백업(Git Push) 진행.
