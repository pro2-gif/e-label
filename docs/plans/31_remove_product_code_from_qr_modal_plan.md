# Plan 31: QR 확인 및 다운로드 팝업 모달에서 제품코드 제거 계획서

## 1. 개요 및 목적
- **사용자 요청 사항**:
  - "qr확인 및 다운로드 클릭시 나타나는 캡쳐본에서 제품코드는 전제품에서 삭제해줘"
- **현상 분석**:
  - 홈 화면의 제품 카드에서 [QR 확인 및 다운로드] 버튼 클릭 시 열리는 `#qr-modal` 팝업 상단에 `CLX-LAP`, `CLX-RJ` 등의 제품코드(`#qr-modal-code`)가 표시되고 있음.
  - 전제품에서 제품코드 표기를 제거하여 제품명만 단정하게 표시되도록 개선.

---

## 2. 작업 상세 내용
### 1) HTML 수정 (`index.html`)
- `#qr-modal-code` 요소를 완전히 숨김(`display: none;`) 처리하거나 제거.

### 2) JavaScript 수정 (`openQrModal`)
- `codeEl.textContent = code;` 로직을 제거하거나 `codeEl.style.display = 'none';`으로 처리.
- QR 코드 생성(`productUrl = ...`)에 필요한 내부 코드 값은 온전히 유지하여 QR 기능 무결성 보장.

---

## 3. 검증 계획
1. Puppeteer 브라우저 테스트:
   - 홈 화면에서 [QR 확인 및 다운로드] 클릭.
   - 모달 상단에 제품코드가 나타나지 않고 제품명만 바로 표시되는지 검증.
   - 스크린샷 캡처 및 시각적 검증.
2. 빌드, 커밋 및 클라우드 푸시.
